# 🌴 GTA VI: VICE DYNASTY — Experiencia Narrativa Interactiva

Una experiencia cinematográfica interactiva ambientada en el estado de **Leonida**, inspirada en el universo de **Grand Theft Auto VI**. Combina cinemáticas híbridas en alta definición, un sistema de toma de decisiones con efecto mariposa, un smartphone integrado (**ViceOS**), radio con música personalizada y un mapa satelital interactivo oficial.

---

## ✨ Características Principales

- 🎬 **Reproductor Híbrido 4K:** Integración de secuencias cinemáticas en video con transiciones fluidas a fotogramas estáticos en alta resolución al concluir cada escena.
- 🔀 **Árbol de Decisiones (Efecto Mariposa):** Cada elección influye en el respeto criminal, las finanzas clandestinas, las estrellas de búsqueda policial y el desenlace de la historia.
- 📱 **Smartphone ViceOS:**
  - 💬 **Misiones & Mensajes (Signal):** Panel superior con el objetivo actual dinámico y chat interactivo con personajes de Leonida.
  - 📻 **ViceRadio:** Estación de música con canciones MP3 personalizadas (Tom Petty, Tame Impala, Bad Bunny, Joy Crookes) y controles de audio.
  - 🗺️ **GPS Satelital:** Visualización rápida de ubicación y puntos de interés de la trama.
  - 📸 **InstaVice:** Feed social fotográfico de las locaciones de Leonida.
- 🗺️ **Mapa Satelital Interactivo de Leonida:** Mapa a escala completa con zoom interactivo, paneo y *blips* GPS fieles al estilo Rockstar Games (Misiones principales, contratos y talleres).
- 🚨 **Sistema Policial Narrativo:** Nivel de búsqueda (0 a 5 estrellas ★) que reacciona a decisiones violentas o de sigilo con sirenas y alertas de radio.
- 👥 **Descubrimiento Progresivo del Equipo:** Conoce a aliados y contactos (Lucia, Jason, Brian Heder, Cal Hampton, Raul Bautista, Boobie Ike) conforme avanzas en los capítulos.

---

## 🛠️ Stack Tecnológico

- **Frontend:** React 19 + TypeScript + Vite
- **Estilos:** TailwindCSS + Lucide Icons
- **Gestión de Estado:** Zustand (Persistencia en LocalStorage)
- **Audio:** Howler.js / Motor de Audio Espacial WebAudio
- **Animaciones:** CSS3 Keyframes & Tailwind Animate

## 🚀 Instalación y Ejecución

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/nahueldlsl/GTA-6.git
   cd GTA-6
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
